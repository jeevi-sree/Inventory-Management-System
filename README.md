# Inventory-Management-System
Data Analyst project using Excel, MySQL, SQL, Power BI and DAX

## Project Overview

A Data Analytics project focused on analyzing grocery inventory data and creating an interactive Power BI dashboard.

The project covers the complete data analysis workflow:

**Excel → Data Cleaning → MySQL → SQL Analysis → Power BI → DAX → Dashboard → Insights**

## Problem Statement

Managing grocery inventory requires monitoring stock levels, sales, product availability, expiry status, suppliers, warehouses, and restocking requirements.

This project transforms raw inventory data into meaningful insights using Excel, MySQL, SQL, Power BI, and DAX.

## Objectives

- Clean and prepare inventory data using Excel
- Store and analyze data using MySQL and SQL
- Analyze stock and sales information
- Identify products requiring restocking
- Analyze expired products
- Analyze suppliers and warehouses
- Calculate total inventory value
- Create an interactive Power BI dashboard
- Generate useful business insights

## Dataset

The dataset contains **990 inventory records** and **16 columns**, including:

- Product ID
- Supplier ID
- Product Name
- Supplier Name
- Category
- Warehouse Location
- Product Status
- Date Received
- Last Order Date
- Expiration Date
- Stock Quantity
- Reorder Level
- Reorder Quantity
- Unit Price
- Sales Volume
- Inventory Turnover Rate
